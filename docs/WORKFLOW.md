# Generic production workflow

1. Define the audience, objective, format, and brand direction in local configuration.
2. Gather sources and record provenance for each factual claim and media asset.
3. Draft content and keep generated voice or owner-recorded voice clearly identified.
4. Review voice by listening to the exact candidate; transcription and signal checks are technical evidence only.
5. Edit the video in the configured external editor and export under human supervision.
6. Record versions, file hashes, provenance, and independent review status for each output.
7. Fix findings and review the changed version again. Approval does not transfer to derivatives.
8. Hand off only independently approved files. Publishing remains a separately authorized human action.
