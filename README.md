# Agentic Content — clean template

A brand-neutral snapshot of the local content-production structure. It contains application modules under `app/`, generic process notes under `docs/`, and an empty `brands/example/` configuration boundary.

Project-specific datasets, outputs, source histories, credentials, production records, and media are not included. The source folder had no `.git`; this snapshot therefore starts with new history and is not an upstream clone. The current public Agentic Content repository is archived, so this folder has no push destination configured.

See `docs/ALIGNMENT.md` for limitations and `docs/WORKFLOW.md` for the intended process.
